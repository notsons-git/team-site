# GameShelf — каталог видеоигр

## Описание проекта

**GameShelf** — веб-сайт для просмотра каталога видеоигр и составления личного списка избранного. Интерфейс выполнен в тёмной цветовой гамме с акцентными фиолетовыми элементами. На главной странице представлены карточки игр с основной информацией о каждой из них.

## Цель сайта

Сделать поиск и выбор видеоигр удобнее: пользователь может просматривать доступные игры, находить их по названию, выбирать жанры и отмечать понравившиеся игры.

## Основные возможности

- **Каталог игр.** Игры представлены в виде карточек, расположенных сеткой.
- **Поиск по названию.** В верхней части каталога предусмотрено поле поиска.
- **Фильтрация по жанрам.** Доступны категории «Все», «RPG», «Экшен», «Приключения», «Платформер» и «Симулятор».
- **Избранное.** На карточках размещены значки сердца для добавления игр в избранное; в верхнем меню есть соответствующий раздел.
- **Краткая информация об играх.** Карточки содержат название, год выпуска, жанры и оценку.

## Содержание главной страницы

В шапке сайта расположены название **GameShelf** и навигационные кнопки «Каталог» и «Избранное». Ниже находятся строка поиска и кнопки выбора жанра. Основное пространство занимает каталог из шести игр, показанных на предоставленном скриншоте:

## Особенности дизайна

Сайт использует минималистичный стиль. Тёмный фон снижает визуальную перегруженность, а фиолетовое выделение активной категории помогает ориентироваться в интерфейсе. Карточки имеют скруглённые углы, крупные тематические значки и компактные текстовые блоки. Оценки выделены жёлтыми звёздами, а избранное обозначено сердечками.

## Целевая аудитория

Сайт предназначен для пользователей, интересующихся компьютерными и видеоиграми, которые хотят быстро просматривать подборку игр и сохранять понравившиеся варианты.

## Заключение

**GameShelf** представляет собой простой и наглядный каталог видеоигр. По представленному скриншоту можно определить основные элементы интерфейса: поиск, жанровые фильтры, карточки игр и раздел избранного. Фактическая работа этих функций, адаптация под мобильные устройства и технологии реализации по одному изображению не проверялись.
