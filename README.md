# 🎮 GameShelf

**GameShelf** — минималистичный каталог видеоигр на чистом **HTML + CSS**, без единой строки JavaScript.

Поиск, фильтры по жанрам, рейтинги, описания и избранное — всё реализовано средствами HTML и CSS.

---

## ✨ Возможности

| Функция | Реализация |
|---------|-----------|
| 🗂 Каталог игр | Статичные карточки с обложкой-эмодзи, названием, годом и рейтингом |
| 🔎 Поле поиска | UI-элемент `input[type="search"]` (без JS не фильтрует) |
| 🏷 Фильтр по жанрам | `radio` + `:has()` — скрывает карточки без нужного `data-genre` |
| ❤️ Избранное | `checkbox` + `label` — сердечко переключается, анимация `pop` |
| 📖 Детали игры | Модальное окно через `:target` (открытие/закрытие ссылками) |
| 🌙 Тёмная тема | Встроена по умолчанию |
| 📱 Адаптивность | Медиазапросы под мобильные экраны |

---

## 🚀 Запуск

Сервер и сборка **не нужны**.

1. Скачайте папку проекта.
2. Откройте `index.html` в любом современном браузере.

```
gameshelf/
├── index.html
├── style.css
└── README.md
```

## 🧩 Как это работает без JavaScript

### Фильтр по жанрам
Выбор жанра — это `radio`-кнопка. При её активации CSS-селектор `:has()` скрывает карточки, у которых в `data-genre` нет нужного жанра:

```css
body:has(#g-rpg:checked) .card:not([data-genre*="rpg"]) { display: none; }
```

### Избранное
Каждая карточка содержит скрытый `checkbox` и связанный с ним `label`-сердечко. Состояние переключается кликом, а вид меняется через `:checked`:

```css
.fav-check:checked + .fav-btn::after { content: "❤️"; }
```

### Модальное окно
Карточка ведёт на якорь `#game-N`, а окно ловит его через `:target`:

```css
.modal:target { visibility: visible; opacity: 1; }
```

Закрытие — ссылка на `#catalog`.

## ⚠️ Ограничения (следствие отказа от JS)

- **Поиск не фильтрует** — поле присутствует только как элемент интерфейса.
- **Избранное не сохраняется** после перезагрузки страницы (нет `localStorage`).
- **Сортировка** по рейтингу/году/названию отсутствует.
- **Отдельной страницы «Избранное»** нет (можно добавить через `:target` + `:has()`).
- Данные игр **захардкожены** в HTML — для добавления игры нужно править разметку.

## 🛠 Технологии

- **HTML5** — семантическая разметка, `input`, `label`, якоря
- **CSS3** — Grid, Flexbox, `:has()`, `:target`, `:checked`, `@keyframes`, `transition`
- **Без JavaScript, без фреймворков, без сборки**

## ➕ Как добавить игру

Скопируйте блок `<article class="card">` в `index.html` и измените:

1. `data-genre` — жанры через пробел (`rpg action adventure`)
2. `id` чекбокса и label — уникальные (`fav-7`)
3. `id` модального окна — уникальный (`game-7`)
4. Эмодзи, название, год, жанры, рейтинг, описание
5. Ссылки `href="#game-7"` и `href="#catalog"` внутри модалки

> ⚠️ Если добавляете **новый жанр**, не забудьте:
> - добавить `radio` + `label` в блок `.genres`;
> - добавить строку `body:has(#g-НОВЫЙ:checked) .card:not([data-genre*="НОВЫЙ"]) { display: none; }` в `style.css`.

## 🎨 Кастомизация

Основные цвета заданы в `:root` в `style.css`:

```css
:root {
  --bg: #0f1117;          /* фон страницы */
  --card: #1a1d27;        /* фон карточек */
  --accent: #6c5ce7;      /* акцент (кнопки, hover) */
  --text: #e8e9f0;        /* основной текст */
  --text-dim: #8a8fa3;    /* второстепенный текст */
  --gold: #f5b301;        /* рейтинг */
}
```
